📋 Quick Guide
현장직원 휴무근무표
천안 아이파크 · 부성 현장 직원의 월간 휴무/근무 현황을 실시간으로 공유하는 웹 기반 시스템입니다.
인터넷이 되는 곳이라면 어디서나 같은 데이터를 확인·수정할 수 있습니다.
🌐 https://i2002da.github.io/ipark-roster/

로고 · 동기화 상태 표시

📅 공휴일 관리 — 휴일 등록
🌙 테마 토글 — 다크/라이트
📑
현장 탭
탭 클릭으로 현장 전환
탭 우측 숫자 = 현재 달 직원 수
현장별 데이터 완전 독립 저장
📅
컨트롤 바
◁ ▷ 월 이동

테이블 아래 = 공지사항
2
현장 추가 · 삭제
①
헤더 🏗 현장 관리 클릭
등록된 현장 목록과 추가 폼이 표시됩니다.
②
현장명 · 전체명 입력 → + 현장 추가
현장명 : 탭에 짧게 표시 (예: 3단지)
전체명 : 근무표 상단 · PDF에 표시 (예: 천안 아이파크시티 3단지)
③
현장 삭제 — 목록의 삭제 버튼
확인 후 삭제. 해당 현장의 모든 데이터가 제거됩니다. 최소 1개 유지.
3
직원 추가 · 수정 · 삭제
+
+ 직원 추가 버튼 → 구분/성명 입력
현재 달 이후에만 반영. 과거 기록 보존.
✎
성명 클릭 → 수정 모달 → 저장 / 삭제
직원 이름을 클릭하면 정보 수정·삭제 가능. 삭제도 현재 달 이후만 적용.
⠿
맨 왼쪽 ⠿ 핸들 드래그 → 순서 변경
현재 달 이후에 반영. 과거 기록 순서 유지.
4
휴무 · 현장미근무 입력
●
날짜 셀 좌클릭 → 휴무(●) 등록/해제
녹색 배경 + ● 표시. 다시 클릭하면 해제. 휴무계에 +1 카운트, 근무인원수에서 제외.
교
날짜 셀 우클릭 → 현장미근무 사유 선택
📚 교육 · ✈ 출장 · 🏥 병가 · 📋 기타 선택.
보라색 배경 + 첫 글자 표시. 휴무계 미포함, 근무인원수에서 제외.

5
일괄 휴무
①
📋 일괄 휴무 버튼 → 패널 펼침
전체 / 평일 / 토요일 / 일요일 / 공휴일 빠른 선택 또는 날짜 개별 클릭
②
✅ 전체 휴무 등록 또는 🗑 전체 휴무 해제
선택한 날짜에 현장 전체 직원 휴무(●)를 일괄 처리합니다.

7
실시간 공유 동작 방식
🟢 헤더의 🟢 실시간 공유 ON 표시 = Firebase 연결 정상. 누구든 변경하면 모든 접속자 화면이 자동 갱신됩니다.
💾 데이터는 Firebase Realtime Database에 저장되며 변경 즉시 다른 접속자에게 전달됩니다. 오프라인 시 자동으로 로컬에 백업됩니다.
