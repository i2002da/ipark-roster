📋 Quick Manual
현장직원 휴무계획표
천안 IPC 통합현장 직원의 월간 휴무·근무 현황을 실시간으로 공유하고 PDF·엑셀로 출력하는 웹 기반 시스템입니다.
🌐 https://i2002da.github.io/ipark-roster/
01
시스템 개요
🏗
다현장 통합 관리
여러 현장을 탭으로 구분하여 각각 독립적으로 직원·휴무 데이터를 관리합니다.
🔄
실시간 공유
Firebase 기반으로 모든 접속자가 동일한 데이터를 실시간으로 확인·수정할 수 있습니다.
📄
PDF·엑셀 출력
A3 가로 PDF와 XLSX 파일로 저장합니다. 공지사항·비고·발령일 이전 셀도 반영됩니다.
📅
공휴일 자동 갱신
앱 시작 시 구글 캘린더 대한민국 공휴일을 자동으로 불러옵니다. 2025~2028년 기본 탑재.
💾데이터는 Firebase Realtime Database에 실시간 저장됩니다. 브라우저를 닫아도 유지되며 다른 기기에서도 동일하게 확인됩니다.
⚠️중요한 월 마감 후에는 반드시 PDF 또는 엑셀로 저장해 두세요.
02
화면 구성
영역위치주요 기능
헤더최상단 고정로고 · 전체 현장 근무/휴무/총원 통계 · 월 이동(◁▷) · 실시간 동기화 상태 · 현장관리 · 공휴일관리 · 테마 · 버전
현장 탭헤더 아래탭 클릭으로 현장 전환. 탭 배지 = 해당 달 직원 수
컨트롤 바탭 아래현장명 · 과거기록 표시 · 일괄 휴무 · 직원 추가 · PDF 저장 · 엑셀 저장
근무표 테이블중앙직원 × 날짜 셀. 좌클릭=휴무, 우클릭=현장미근무. 헤더와 좌측 4열 고정(스크롤 시 유지)
근무인원수 행테이블 하단날짜별 실제 현장 근무 인원 자동 집계
공지사항테이블 아래현장별·월별 공지 입력. PDF에 자동 포함
03
현장 추가·수정·삭제
①
헤더 🏗 현장 관리 클릭
등록된 현장 목록과 추가 폼이 표시됩니다.
②
현장 추가 — 현장명·전체명 입력 후 + 현장 추가
현장명: 탭에 짧게 표시 (예: 3단지)  ·  전체명: 근무표 상단·PDF에 표시
③
현장명 수정 — ✎ 수정 버튼 클릭
인라인 입력 폼이 열립니다. 수정 후 저장하면 탭·근무표·PDF에 즉시 반영됩니다.
④
현장 삭제 — 삭제 버튼 클릭 후 확인
해당 현장의 모든 데이터가 삭제됩니다. 최소 1개 현장은 유지됩니다.
04
현장 탭 순서 변경
⠿
현장 관리 모달에서 ⠿ 핸들 드래그
목록 좌측 ⠿ 핸들을 마우스로 잡고 원하는 위치로 드래그하면 탭 순서가 변경됩니다. 변경 즉시 Firebase 동기화.
05
직원 추가
①
컨트롤 바 + 직원 추가 클릭
과거 달 조회 중에는 버튼이 표시되지 않습니다.
②
구분·성명·현장 발령일 입력 후 추가
발령일 미입력 시 기본값 2026-04-01 자동 적용. 발령일 이전 날짜는 비활성(빗금) 처리됩니다.
ℹ️직원 추가는 현재 달 이후에만 반영됩니다. 이전 달 기록은 보존됩니다.
06

구분·성명·발령일 수정 후 저장. 현재 달 이후에만 반영됩니다.
🗑
삭제 버튼 → 확인 후 삭제
현재 달 이후 근무표에서만 삭제됩니다. 이전 달 기록은 보존됩니다.

18
자주 묻는 질문
Q
2026년 4월 이전으로 이동이 안 돼요.
시스템 최소 표시 월이 2026년 4월로 설정되어 있습니다. ◁ 버튼이 비활성화됩니다.
Q
직원을 추가했는데 이전 달에도 나타나요.
발령일을 올바르게 설정하면 해결됩니다. 직원 수정에서 발령일을 변경하세요.
Q
공휴일이 표시되지 않아요.
📅 공휴일 관리 → 📡 구글 캘린더 자동 업데이트를 클릭하세요. 앱 시작 시 자동으로도 갱신됩니다.
Q
다른 기기에서 변경한 내용이 안 보여요.
헤더의 동기화 상태가 🟢인지 확인하세요. 🔴이면 인터넷 연결을 확인하고 새로고침하세요.
Q
현장미근무와 휴무의 차이는?
휴무(●)는 휴무계에 +1 카운트됩니다. 현장미근무(교육·출장 등)는 휴무계에 포함되지 않고 근무인원수에서만 제외됩니다.
